# ateli

> The Devin killer. Hi-end cloud-native AI software agent built on top of frontier models.

## What is this?

ateli is an enterprise-grade AI software engineering agent. Instead of training our own (worse) model, we go all-in on:

- **Killer tooling** — time-travel debugging, parallel reality testing, production shadow mode, visual regression agents, synthetic user swarms, and more.
- **Variant-grade RAG** — 7-layer retrieval (lexical, semantic, AST, graph, temporal, social, behavioral) with code-aware chunking.
- **Per-tenant cloud** — BYOC (Bring Your Own Cloud), data sovereignty, tenant-isolated knowledge graphs.
- **Every surface** — Slack, Teams, Discord, IDE (VS Code/Cursor/JetBrains), mobile, voice, email, CLI, API.
